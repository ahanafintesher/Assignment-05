## ✨ Features

- 🔐 **Login System** — Secure sign-in with demo credentials
- 📋 **Issue Listing** — View all 50+ issues in a card-based layout
- 🔍 **Search Issues** — Search issues instantly by title or description
- 🗑️ **Delete Issues** — Remove issues directly from the dashboard
- 🏷️ **Priority Labels** — High, Medium, Low priority indicators
- 🟢 **Status Filter** — Filter by All / Open / Close
- 🏷️ **Tag System** — Bug, Enhancement, Documentation, Good First Issue, etc.
- 📱 **Responsive Design** — Works on all screen sizes

---

## 📦 Dependencies

- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework
- [DaisyUI](https://daisyui.com/) — Tailwind CSS component library
- Vanilla JavaScript (ES6+) — No framework needed
